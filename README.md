# Conhecendo o While Loop em Python

Projeto educacional em Python criado para praticar o uso de `while` em um fluxo simples de promocao de produto.

O exercicio simula uma promocao em que o valor de uma mercadoria diminui gradualmente ate atingir um valor minimo definido pelo usuario.

## Objetivo do estudo

O objetivo e compreender como uma estrutura de repeticao pode executar uma acao enquanto uma condicao permanecer verdadeira. Neste caso, o programa continua exibindo o preco promocional enquanto o valor atual for maior que o valor minimo informado.

## Problema praticado

O projeto usa um exemplo comercial simples para estudar logica de repeticao: calcular e exibir reducoes sucessivas de preco ao longo de dias de promocao.

## Como funciona

O script solicita:

- nome do produto;
- valor inicial;
- valor de desconto;
- intervalo de dias;
- valor minimo.

Depois, usa um `while` para reduzir o preco e imprimir as mensagens de promocao enquanto a condicao definida continuar valida.

## Conceitos utilizados

- Entrada de dados com `input`.
- Conversao de valores com `float` e `int`.
- Repeticao com `while`.
- Atualizacao de variaveis durante o loop.
- Condicao de parada.
- Formatacao de mensagens no terminal.
